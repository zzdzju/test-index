# 精准营养技术网 · 原型站

静态原型，双击 `index.html` 即可在浏览器打开；也可用任意静态服务器托管。

## 目录结构

```
index.html            首页（网站简介 + 40 栏目网格 + 页脚）
pages/*.html          40 个栏目详情页 + 4 个导航页（单位简介 / 新闻报道 / 意见建议 / 合作加盟）
assets/style.css      全站样式
assets/site.js        右侧咨询框 / 回到顶部等交互
build.py              生成脚本（改内容后重新运行 python build.py 即可重建全站）
README.md             本说明
```

## 布局要点

- 顶部深色导航（单位简介 / 新闻报道 / 合作加盟 / 意见建议 / 联系我们），首页正文居中标题 + 红色分隔线。
- 首页顶部是轮播区（左右滑动 + 自动播放，约 5.2 秒一页）：第 1 页是本站简介，其余可放新闻播报、产品介绍等；支持箭头、圆点、触摸滑动，鼠标悬停自动暂停。
- 轮播内容在 build.py 的 SLIDES 列表中维护：加一条记录 = 多一个滑动页，重跑 build.py 生效。
- 轮播下方直接平铺 40 个栏目，每排 5 个，点击卡片进入详情页。
- 右侧边缘悬浮"顾客咨询"竖标签，点击展开表单（原型不提交，仅本地提示）。
- 右下角三个圆形工具按钮：电话、微信、回到顶部。
- 页脚：主办单位、地址、电话、邮箱、二维码、备案号、科普免责声明。

## 维护首页轮播

首页顶部轮播的全部内容都在 `build.py` 的 `SLIDES` 列表里（搜 `SLIDES = [`），**它是唯一配置点**。
不要直接改 `index.html` —— 每次运行 `build.py` 都会重建它，手改会被覆盖。

**字段说明**

| 字段 | 说明 |
| --- | --- |
| `kind` | `intro` 本站简介 / `news` 新闻播报 / `product` 产品介绍。决定右侧图标（见 `SLIDE_ART`） |
| `title` | 标题，显示在卡片最上方一行（仅 `news` / `product`） |
| `source` | 来源。与 `date` 同行，紧贴标题下方（如「来源：央视新闻 2026-09-22」） |
| `date` | 日期，可留空 |
| `text` | 正文段落，列表，每项一段 |
| `href` | 「查看详情」跳转地址（站内如 `pages/news.html`，或 `https://` 外链）；留空则不显示按钮 |
| `more` | 按钮文字，默认「查看详情」 |
| `html` | 仅 `kind=intro` 使用，直接写 HTML 片段 |
| `art` | 可选。覆盖右侧图标：`("主图标", ("徽章1", "徽章2"))`，键名见文件里的 `ICONS` |
| `tag` | 已停用（左上角不再显示编号与标签），字段保留备用 |

**新增一个滑动页**：在 `SLIDES` 列表里追加一条字典即可，列表顺序 = 显示顺序。例如加一条产品介绍：

```
{
    "kind": "product",
    "title": "精准营养食谱设计服务",
    "text": ["按个人体检数据与饮食习惯，输出可执行的每日食谱。",
             "覆盖个人、家庭、团餐、食堂、餐厅五类场景。"],
    "date": "2026-09-24",
    "href": "pages/personal-recipe.html",
    "more": "了解详情",
},
```

**改完执行两步**

```
python build.py          # 重建全站（index.html + pages/*）
python _dev/publish.py   # 发布有变化的文件，并逐字节回验
```

`_dev/publish.py` 会自动只上传有变化的文件（本机 `git push` 到 github.com 会被网络重置，
故统一走 GitHub Contents API）。加 `--dry` 只列差异不上传；加 `--cdn` 额外抓线上页面做端到端比对。
