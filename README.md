# 精准营养技术网

静态站，双击 `index.html` 即可在浏览器打开，也可用任意静态服务器托管。
线上地址：https://zzdzju.github.io/test-index/

## 目录结构

```
index.html            首页（顶部轮播 + 40 栏目网格 + 页脚）
pages/*.html          40 个栏目详情页 + 4 个导航页（单位简介 / 新闻报道 / 意见建议 / 合作加盟）
assets/style.css      全站样式
assets/site.js        轮播播放 / 咨询框 / 回到顶部等交互
assets/wechat-qr.png  页脚微信二维码（换图后重跑 build.py 生效）
build.py              唯一数据源：改内容后重新运行 python build.py 重建全站
_dev/preview.py       轮播预览截图工具（开发用，不上线）
_dev/publish.py       发布 + 回验工具（开发用，不上线）
README.md             本说明（由 build.py 生成，不要直接改本文件）
```

> 注意：`index.html`、`pages/*.html`、`assets/style.css`、`assets/site.js`、`README.md`
> 全部是 build.py 的**产物**，每次运行 build.py 都会重建。要改内容，只改 `build.py`。

## 日常维护：三条命令

```
python build.py                # 重新生成全站
python _dev/publish.py --dry   # 只看本地与线上的差异（可选）
python _dev/publish.py         # 上传有变化的文件，并逐字节回验
```

`_dev/publish.py` 会比对 51 个站点文件，**只上传有变化的**，上传后再从 GitHub 拉回来逐字节比对，
看到 `ALL_PASS` 才算发布成功。加 `--cdn` 可额外抓线上页面做端到端验证。
`build.py` 与 `_dev/` 不在上传白名单里，不会被传上去。

## 维护首页轮播

轮播的唯一配置点是 `build.py` 里的 `SLIDES` 列表（搜 `SLIDES = [`）。
**列表顺序 = 显示顺序**，加一条记录就多一个滑动页。

| 字段 | 说明 |
| --- | --- |
| kind | intro 本站简介 / news 新闻播报 / product 产品介绍，决定右侧的图标图示 |
| title | 标题，显示在卡片最上方（news / product） |
| source | 来源，与 date 同行，紧跟标题下方、左对齐 |
| date | 日期，可留空 |
| text | 正文段落列表，每项一段 |
| href | 底部按钮的跳转地址（站内如 pages/news.html，或 https 外链）；留空则不显示按钮 |
| more | 按钮文字，默认「查看详情」 |
| html | 仅 kind=intro 使用，直接写 HTML 片段 |
| art | 可选，覆盖右侧图标：(主图标, (徽章1, 徽章2))，键名见 ICONS |
| tag | 已停用（左上角不再显示编号与标签），字段保留备用 |

加一页的写法：

```python
{
    "kind": "product",
    "title": "精准营养食谱设计服务",
    "text": ["按个人体检数据与饮食习惯，输出可执行的每日食谱。",
             "覆盖个人、家庭、团餐、食堂、餐厅五类场景。"],
    "date": "2026-09-24",
    "href": "pages/personal-recipe.html",
    "more": "了解详情",
},
```

相关常量：`SLIDES`（内容）、`SLIDE_ART`（每类的主图标与两枚徽章）。
自动播放间隔是卡片上的 `data-interval`（5.2 秒），底部圆点本身就是计时进度。

## 维护栏目正文

40 个栏目的标题、简介与正文都在 `build.py` 的 `CONTENT` 字典里，格式为：

```
"slug": ("栏目标题", "卡片上的一句话简介", [ 正文块 ]),
```

正文块支持五种：`("h2", 文本)` 二级标题、`("p", 文本)` 段落、`("ul", [条目])` 列表、
`("note", 文本)` 灰底提示框、`("table", (表头, [行]))` 表格。

栏目的分组与顺序在 `SECTIONS`（`ORDER` 由它生成，共 40 项，带断言校验），
每张卡片的线性图标在 `ICONS`。

三个通用常量：

- `SERVICE_FEE`：多个栏目共用的「服务方法与费用」板块，改一处即可全站生效；
- `DISCLAIMER`：输出到每个栏目页正文末尾的科普免责声明；
- `PENDING_SECTIONS`：内容仍为占位的栏目（目前是证书页与图书页），其详情页标题后保留「原型稿」角标。
